# 🚀 Aman Codex Portfolio

Welcome To My Personal **Portfolio** Website!
This project showcases my work, skills, and ways to connect with me — built with pure **HTML**, **CSS**, and **JavaScript**.

---

## 📌 Features

- 🎥 Animated Background Video
- 🎵 Background Music Toggle
  - Navbar button control
  - Footer click sync
- 📱 Fully Responsive Design
- ✨ Smooth Animations
  - Typing effect
  - Hover effects
- 🧩 Project Showcase Section
- 📬 Contact Section with Social Links
- 🔄 Auto Scroll to Top on Refresh

---

## 🛠️ Tech Stack

- **HTML5** – Structure of the website
- **CSS3** – Styling, animations, responsiveness
- **JavaScript (Vanilla)** – Interactivity (music toggle, scroll behavior)

## 🎮 Key Functionalities

### 🔊 Music Toggle System

- Play/Pause background music
- Sync between navbar and footer controls
- Default volume set to 30%

### 🔄 Scroll Reset

- Automatically scrolls to top on page refresh

### 🎥 Animated Background

- Full-screen video background
- Subtle animations for dynamic feel

### 📱 Responsive Design

- Adapts to various screen sizes (mobile, tablet, desktop)

### ✨ Smooth Animations

- Typing effect for headings
- Hover effects on buttons and project cards

### 📬 Contact Section

- Social media links with icons
- Email contact form (optional)

### 🧩 Project Showcase

- Display of projects with images and descriptions
- Links to live demos and GitHub repositories

## 🖼️ Sections Overview

- Home → Introduction & title animation
